## Projektin kuvaus

Tehtävä 5.3 GitHubin käyttö

## Käyttöohje

1. Luo GitHub -tili. Käytä HAMKin antamaa sähköpostia.
2. Kirjaudu GitHubiin.
3. Avaa linkki: https://github.com/petrinumminen/harjoitus5-template
4. Valitse "Use this template".
5. Luo oma repository. Nimeä se muotoon harjoitus5-etunimi-sukunimi
6. Kloonaa repository omalle koneellesi.
7. Täytä README.md tiedosto.
8. Lähetä muutokset GitHubiin.
9. Luo tiedosto main.py ja lisää siihen FoCar-projektissa tarvittavat kirjastot.
10. Lähetä muutokset GitHubiin.
11. Palauta lopuksi oman repositorysi osoite tämän tehtävän palautuksena.
